# Generated content snapshot

These files are generated by `pnpm content:sync` from the project's personally curated Notion source. The application treats them as a read-only, versioned runtime snapshot. The same atomic sync also owns `public/content/search-index.json`; do not edit these generated targets by hand.

Manifest version 4 preserves existing slug history while tracking the media-franchise data source, counts, and stable slug map. It retains the five Notion source contracts, record counts, fixture IDs, and stable slug maps without media entries. Media reuse state lives in per-record JSON descriptors in the configured state bucket, which defaults to the media bucket, while the snapshot contains the public image URLs and presentation fields required at runtime. Generated scenario stills, source posters, and franchise images are immutable WebP objects in R2 and are not stored in this directory.
