# Generated content snapshot

These files are generated by `pnpm content:sync` from the project's personally curated Notion source. The application treats them as a read-only, versioned runtime snapshot. The same atomic sync also owns `public/content/search-index.json` and `public/media/generated`; do not edit any of these generated targets by hand.
