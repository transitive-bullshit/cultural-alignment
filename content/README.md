# Generated content snapshot

These files are generated by `pnpm content:sync` from the project's personally curated Notion source. The application treats them as a read-only, versioned runtime snapshot. The same atomic sync also owns `public/content/search-index.json`; do not edit these generated targets by hand.

The next authenticated sync migrates the checked manifest from version 2 to version 3 after it seeds R2 descriptors. Version 3 retains the Notion source contract, record counts, fixture IDs, and stable slug maps without media entries. Media reuse state then lives in per-record JSON descriptors in the configured state bucket, which defaults to the media bucket, while the snapshot contains the public image URLs and presentation fields required at runtime. Generated WebP bytes are immutable objects in R2 and are not stored in this directory.
