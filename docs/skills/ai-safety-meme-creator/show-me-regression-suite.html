What happens in one test

  1. 1 · Evidence A real review note identifies a recurring failure or success.
  2. 2 · Probe A fictional scene and obvious synthetic image isolate that behavior.
  3. 3 · Agent Codex reads the current skill and returns a structured composition plan.
  4. 4 · Oracle Vitest independently checks copy, geometry, source frames, and constraints.
  5. 5 · Evidence A deterministic render, preview, logs, and evaluation are retained.

Agent sees

SKILL.md, fictional request, attached images, named protected regions, and the output schema.

Agent does not see

Expected template, exact geometry thresholds, golden review notes, forbidden ingredients, or pass/fail logic.

What Vitest checks

Idea discipline

One AI bridge, one recognition hinge, correct caveats, and no reuse of a direction the reviewer already rejected.

Copy

Locked wording, canonical order, punctuation provenance, word and semantic-line limits, and no test-language contamination.

Layout

Native template choice, separated zones, honest top/bottom slots, no box overlap, and no coverage of faces, props, or readouts.

Typography

Minimum type size, usable width, feasible line wrapping, enough vertical space, contrast, and visible code indentation.

Image integrity

Known source IDs, distinct before/after files, correct frame order, format, and protection of the scene’s visual proof.

Harness reliability

Structured-output schema parity, opaque temp staging, subprocess timeout, process-tree shutdown, and retained failure diagnostics.

What the first live calibration found

  • Caught · face-safe overlay
    Added a second idea line and shrank the type below the fixture’s hero-size floor.
  • Caught · before / after
    Used the right images in the right order, but claimed one physical line where two were needed.
  • Caught · canonical meter
    Selected the wrong template and duplicated text over the protected readout.
  • Accepted · dialogue
    Correctly reused real source-native dialogue wells; the oracle was relaxed to allow it.
  • Accepted · nested code
    The plan was right. Its render exposed and then fixed an indentation bug in the test harness.
  • Healthy signal
    Some good outputs pass and known bad patterns fail; the evaluator is not simply rejecting everything.

Proposed skill revision

Current shape

  • One 2,696-word file handles every branch
  • Important rules repeat and compete for attention
  • Prose metadata and passing booleans are self-reported
  • Locked copy and cleanup rules can conflict
  • The producing agent also judges its own taste

Recommended shape

  • Short router plus focused editorial, composition, and revision references
  • Explicit precedence: locked input wins or the result is blocked
  • One deterministic renderer and one versioned result manifest
  • Measured hashes, transforms, glyph boxes, fonts, and physical lines
  • Objective checks first; independent critic handles taste
