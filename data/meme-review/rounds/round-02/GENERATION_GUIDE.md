# Round two part workflow

The cross-round rules in `../../GENERATION_POLICY.md` are authoritative. In particular, a bare dislike or a dislike of concept/text is terminal: do not iterate on it, paraphrase it, or reuse its joke.

For each assigned part:

1. Read `TASTE_PROFILE.md`, `DRAFT_FEEDBACK_INTEGRATION.md`, the matching round-one ideas, the exact round-one feedback entries, and the source scenario records in `content/snapshot/scenarios.json` plus their concept/source metadata.
2. Inspect the curated-frame reference sheet or source image. Annotate each unique asset's protected regions once. Protect the recognition hinge, not only faces.
3. Keep every liked ID unless a newer review of that exact direction rejects it. Apply the newest explicit feedback to its current version; leave praised copy intact. Give every surviving liked version a composition pass.
4. Remove every neutral, disliked, notes-only, or untouched direction. A disliked direction may be revised only when its note explicitly requests a bounded execution fix or preserves a named ingredient; otherwise start from a different hinge, framing device, ingredient set, and meme format. Generate enough distinct replacements to leave exactly three active ideas. New IDs must be higher than every round-one suffix and any exposed draft ID for that scenario.
5. Prefer one strong beat. Preserve canonical wording, spelling, chronology, character voice, code indentation, and state ordering.
6. Author an honest renderer-v2 preview using only assets that exist in the matching asset part. Always start with a familiar text-on-image overlay and allow slight overlap with incidental scene detail. Try alternate overlay positions, line breaks, and modestly smaller readable type before using a band, sidecar, contain mode, wider frame, or blurred extension; those are last-resort fallbacks only when every overlay would meaningfully hide the recognition hinge.
7. Critique each survivor against round-one taste, fill every score and calibration field, and revise before marking all four glance checks true.

The active part and asset-part files are exclusively yours while assigned. Do not edit the immutable round-one archive, generic `data/meme-review/*.json`, or the original `data/meme-idea-parts/` files.
