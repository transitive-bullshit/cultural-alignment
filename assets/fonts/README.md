# Social-image fonts

`barlow-condensed-latin-800-normal.woff` is the Latin ExtraBold subset of Barlow Condensed v13, copied from `@fontsource/barlow-condensed` so Next.js can trace it into the scenario social-image function without depending on a runtime `node_modules` layout.
